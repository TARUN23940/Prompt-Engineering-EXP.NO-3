EX.NO:3 Exploring the different types of prompts- Straightforward Prompts - Tabular Format Prompting - Missing Word Prompting - Preceding Question Prompting.

Aim: To write the prompts for the following prompt types for 2 different scenarios of Each type.

1.Straightforward Prompts

2.Tabular Format Prompting

3.Preceding Question Prompting

4.Missing Word Prompting

Explanation - Any one use case from Unit 5 or any 2 own use cases with the unit 2 Prompt type

Procedure:

Write 2 different prompts for different use cases, refer the following Examples

Example:

Straightforward Prompts:

• "Define photosynthesis in one sentence."

"List three advantages of electric vehicles."

Tabular Format Prompting:

• "Compare and contrast AC and DC current in a table."

• "Provide a table listing five programming languages, their paradigms, and one use case each."

Preceding Question Prompting:

• "Why is climate change a global concern? Explain how greenhouse gases contribute to global warming."

• "How do vaccines work? Describe the process of immunization in simple terms."

Missing Word Prompting:

• "The capital of France is ____."

• "In photosynthesis, plants absorb sunlight to produce ____."

OUTPUT:
~~~
1. Straightforward Prompts

Description: Direct, one-step instructions for quick facts.

Scenario A: Geography

Prompt: "Name the largest ocean on Earth."

Result: The Pacific Ocean.

Scenario B: Sports

Prompt: "How many players are on a standard soccer team on the field?"

Result: 11 players.

2. Tabular Format Prompting
   
Description: Organizing data into a brief, scannable table.

Scenario A: Programming

Prompt: "Table of Python vs. C++: Paradigm and Execution."

Result:
| Language | Paradigm       | Execution   |
| :---     | :---           | :---        |
| Python   | Multi-paradigm | Interpreted |
| C++      | Multi-paradigm | Compiled    |

Scenario B: Geometry

Prompt: "Table of Triangle, Square, and Pentagon: Number of sides."

Result:
| Shape    | Sides |
| :---     | :---  |
| Triangle |   3   |
| Square   |   4   |
| Pentagon |   5   |

3. Preceding Question Prompting

Description: Establishing context with a question before asking for an explanation.

Scenario A: Health

Prompt: "What is hydration? Briefly explain why water is vital for joints."

Result: Hydration is maintaining fluid balance. Water acts as a lubricant for joints, preventing friction and absorbing shock.

Scenario B: Electricity

Prompt: "What is a conductor? Briefly explain why copper is commonly used in wiring."

Result: A conductor allows electricity to flow easily. Copper is used because it has high conductivity and is relatively inexpensive.

4. Missing Word Prompting

Description: A completion task for specific terminology.

Scenario A: Literature

Prompt: "The legendary sword of King Arthur is named ____."

Result: Excalibur.

Scenario B: Chemistry

Prompt: "The pH scale ranges from 0 to 14; a pH of 7 is considered ____."

Result: Neutral.
